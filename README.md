# Abrham Achemo

AI engineer, independent. I build agent systems that have to work on the first
try: structured outputs, verification steps, graceful fallbacks, and containers
that run on AMD GPUs under ROCm.

**What I work on**

- Retrieval and document-understanding agents over messy, mixed-format inputs
  (PDF, images, spreadsheets, logs) — including the parts that usually break:
  withdrawn revisions, encrypted files, binary junk.
- Web-grounded agents that cite what they used and refuse when the evidence
  isn't there, instead of guessing.
- Reliability engineering around models: self-checks, deterministic fallbacks,
  reproducible Docker builds.
